* DOC_ID
* DOC_CODE
* DOC_NAME
* BUSINESS_TYPE
* CLIENT
* ACTIVE
* CODE

In particular:

* `CLIENT = R` for DOC_ID 90–101.
* `CLIENT = C` for DOC_ID 102–134.
* `BUSINESS_TYPE = B` for all records.
* `ACTIVE = 1` for all records.

Preserve the supplied `CODE` values exactly.

## 4. Idempotent Load

The operation must be safe to run repeatedly.

Do NOT blindly insert all records every time.

For each record:

```text
If DOC_CODE does not exist:
    INSERT

If DOC_CODE already exists:
    UPDATE the record with the supplied values

Never create duplicates.
Never delete unrelated records.
```

Use the application's database technology and existing ORM/query framework.

If the table has a unique constraint on `DOC_ID`, use that appropriately.

Prefer `DOC_CODE` as the business-level unique identifier if the existing schema supports it.
